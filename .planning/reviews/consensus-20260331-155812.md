## MUST FIX (CRITICAL — blocks build/tests)

### 1. FusedEnrollmentFlowTests.swift: `profiles()` compile error
**Votes**: 5 (test-coverage, build, task-spec, kimi, glm, minimax, codex)

Three test methods call `await speakerStore.profiles()` which does not exist as a public API.
`profiles` is a `private var [SpeakerProfile]` on `SpeakerProfileStore`.

The correct public API is `profileSummaries()` → `[SpeakerProfileSummary]`.

**Fix required in** `Tests/HandoffTests/FusedEnrollmentFlowTests.swift` lines 78, 139, 154:
```swift
// WRONG:
let profiles = await speakerStore.profiles()
XCTAssertFalse(profiles.isEmpty, ...)
let ownerProfile = profiles.first(where: { $0.role == .owner })

// CORRECT:
let summaries = await speakerStore.profileSummaries()
XCTAssertFalse(summaries.isEmpty, ...)
let ownerSummary = summaries.first(where: { $0.role == .owner })
// Note: SpeakerProfileSummary has id, displayName, role, enrollmentCount, lastSeen
// No .embeddings field — adjust assertions accordingly
```

## SHOULD FIX (MEDIUM — 2+ votes)

### 2. captureSegment() is semantically wrong for ambient noise baseline
**Votes**: 4 (quality-patterns, error-handling, kimi, minimax)

`recordRoomNoise()` calls `captureSegment(durationSeconds: 20.0)` but this method:
- Waits for speech onset (RMS >= 0.008) before starting its internal timer
- Requires ~3s of voiced speech before auto-stopping early
- In a genuinely quiet room, will wait up to 26s (20 + 6 buffer) then return trailing audio

For a noise baseline, what's needed is a **raw timed capture** with no speech gating.

Options:
- Use `recentAudio(seconds: 5.0)` after a short delay (reads from the ring buffer, already running)
- Add a `captureRawSegment(durationSeconds:)` overload that skips speech detection
- Accept current behavior as a heuristic (captures 26s of ambient if user stays quiet, gets RMS)

**Recommended minimal fix**: Add a comment to `recordRoomNoise()` explaining the behavior, and reduce `noiseDuration` to something more reasonable (5s) since the current 20s will behave as ~26s in a quiet room.
