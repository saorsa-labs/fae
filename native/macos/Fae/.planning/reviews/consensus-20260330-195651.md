### 3. LLMEngine protocol / AdapterCapable protocol
**Votes**: 4/15
New adapter methods (loadAdapter, unloadAdapter, swapAdapter, isAdapterLoaded) must be surfaced via the LLMEngine protocol in MLProtocols.swift OR a new AdapterCapable protocol. Without this, consumers calling via protocol won't see these methods, and MockLLMEngine can't stub them for tests.

### 4. Define typed error cases for adapter failures
**Votes**: 3/15
Plan spec says "typed errors for missing directory, missing adapter_config.json, incompatible format" without specifying the type. Extend MLEngineError with:
- `.adapterNotFound(URL)` — directory doesn't exist
- `.adapterConfigMissing(URL)` — directory exists but no adapter_config.json
- `.adapterIncompatible(String)` — loaded but model rejects it
