# Open gaps — ACP port + cross-platform pivot (2026-06-16)

**Purpose.** A single inventory of in-flight, incomplete work so nothing is lost as focus
shifts to the **llama.cpp serving pivot** and broader cross-platform work. This is a *gaps*
list (what's left), not a design — each area points at the doc that owns its design.

**The pivot that frames everything (2026-06-16):** retire the vendored **mistral.rs** brain;
adopt a prebuilt **`llama-server` subprocess sidecar** behind the existing `ProviderAdapter`
seam (cross-platform serving: Metal/CUDA/Vulkan/ROCm; Gemma 4 12B via Unsloth dynamic GGUF
quants; runtime GGUF-LoRA). Validated end-to-end today (base ↔ personalized via per-request
LoRA scale on one server). Design: [`cross-platform-brain-llamacpp-2026-06-16.md`](./cross-platform-brain-llamacpp-2026-06-16.md)
(supersedes [`cross-platform-overnight-training-2026-06-16.md`](./cross-platform-overnight-training-2026-06-16.md)).
This makes the **daemon the cross-platform spine**: it will supervise *two* subprocess sidecars
(llama-server + per-turn ACP agent servers) under the existing `DaemonProcessRegistry` +
parent-watch.
